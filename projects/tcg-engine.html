TCG Engine

A browser tool for comparing opening-hand odds and exploring tournament qualification scenarios in trading card games.

Open Live Demo Source Code ↗

Built with

  • JavaScript
  • Chart.js
  • HTML & CSS

The problem

Changing the number of key cards in a deck affects opening-hand consistency. Players need a way to compare those changes and see the assumptions behind the odds.

What it does

  • Calculate the chance of drawing one target group or two separate groups.
  • Compare nearby card counts and inspect the distribution as a chart or table.
  • Track round results and explore possible tournament outcomes.

Separate probability logic from the interface

A dedicated calculations module uses combinations to calculate draws without replacement. Logarithmic calculations avoid overflowing large combination values. The interface validates inputs and presents the results as percentages, charts, and tables.

Scope & limitations

Deck calculations exclude searches and mulligans. Tournament projections are planning estimates using simplified win and tie assumptions; they are not qualification guarantees.
